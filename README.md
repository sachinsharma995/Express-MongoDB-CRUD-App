# Express MongoDB CRUD App

A simple and responsive CRUD (Create, Read, Update, Delete) application built using Node.js, Express.js, MongoDB, Mongoose, and EJS.

## 🚀 Features

- Create Users
- Read Users
- Update Users
- Delete Users
- MongoDB Database Integration
- Responsive UI using Tailwind CSS
- Server-side Rendering with EJS

---

## 🛠️ Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- Tailwind CSS

---

## 📂 Project Structure

```bash
├── models
├── public
├── views
├── app.js
├── package.json
└── README.md
```

## 📸 Functionalities

- Add new users with image URL
- Display all users
- Edit user details
- Delete users from database
